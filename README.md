# Cercle — web app

Recommandations de films et de livres en vidéo. Vite + React + TypeScript, PWA, Supabase, Netlify.

```bash
cp .env.example .env.local
npm install
npm run dev      # http://localhost:5173
npm run check    # typecheck + lint + format + tests
```

Spécification : `CLAUDE.md`. Avancement : `PROGRESS.md`.
